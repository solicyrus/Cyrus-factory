# 🏭 CYRUS TEAM — Factory HQ v2.0

کارخونه ایجنت واقعی — نه ویترین. هر ایجنت یه ماژول پایتونه که واقعاً کار می‌کنه، و هیچ‌چیز بدون تأیید تو (Approve) اجرا نمی‌شه.

**جدید در v2.0:** 🧠 حلقه یادگیری — هر ایجنت از تأیید/رد شدن‌هاش درس می‌گیره و دفعه بعد بهتر عمل می‌کنه. ایجنت‌های خلاق هم می‌تونن از هوش مصنوعی قوی (همون کلیدهای بات Cyrus AI) استفاده کنن.

## 🧠 حلقه یادگیری (Learning Loop) — چطور ایجنت‌ها «باهوش‌تر» می‌شن

این جادو نیست — یه چرخه ساده و صادقانه‌ست:

1. **قبل از اجرا:** هر ایجنت با `get_lessons()` درس‌های گذشته‌ش رو می‌خونه (تأیید شده‌ها و رد شده‌ها + یادداشت‌های تو)
2. **حین اجرا:** ایده‌های خلاق از زاویه‌های ردشده دوری می‌کنن؛ Content Writer تیتری که قبلاً رد شده رو تکرار نمی‌کنه
3. **بعد از تأیید/رد:** وقتی تو روی Approve یا Reject می‌زنی (می‌تونی یه یادداشت هم بنویسی)، نتیجه با `log_outcome()` توی `memory/<agent>.jsonl` ذخیره می‌شه
4. **دفعه بعد:** ایجنت یادداشت تو رو می‌خونه و رفتارش رو اصلاح می‌کنه

هر چی بیشتر تأیید/رد کنی (با یادداشت)، ایجنت‌ها دقیق‌تر می‌شن. حافظه هر ایجنت یه فایل ساده JSONL توی پوشه `memory/`ـه.

## 🤖 هوش مصنوعی قوی برای ایجنت‌های خلاق (اختیاری)

۸ ایجنت خلاق/قضاوتی (Idea Maker، Ads Angles، FAQ Builder، Nightly Reporter، Content Writer، Support Tone، SEO Writer، Testimonial Drafter) می‌تونن از یه AI قوی استفاده کنن. **کلید جدید لازم نیست** — از همون کلیدهایی که بات Cyrus AI رو روشن می‌کنن استفاده کن:

1. فایل `.env.example` رو کپی کن به اسم `.env` (توی همین پوشه factory)
2. کلید موجودت رو بذار: `ANTHROPIC_API_KEY=...` (اول این امتحان می‌شه، بعد OpenAI)
3. کارخونه رو عادی اجرا کن — مصرف از همون اعتبار فعلی‌ته

**هزینه:** هر اجرا چند سنت (مدل‌های سبک: claude-sonnet و gpt-4o-mini). بدون کلید هم همه‌چیز کار می‌کنه — فقط حالت قانون‌مند (rule-based).

⚠️ **فایل `.env` واقعی رو هیچ‌وقت توی git نذار.** فقط روی لپ‌تاپ خودت می‌مونه.

## اجرا روی لپ‌تاپ
```bash

./venv/bin/python app.py       # ویندوز: venv\Scripts\python app.py
```

## داشبورد HQ
- 🗺️ کارت دپارتمان‌ها + ایجنت‌ها (دکمه ▶ Run)
- ✅ صف تأیید (Approval Queue): هر پیشنهاد ایجنت اینجاست — Approve یا Reject با یه کلیک (+ یادداشت اختیاری که به ایجنت درس می‌ده)
- 📝 لاگ فعالیت‌ها (هر ۱۵ ثانیه تازه می‌شه)

## API
- `GET /api/status` — وضعیت کارخونه
- `GET /api/agents` — لیست ۲۰ ایجنت
- `POST /api/run/<agent_id>` — اجرای ایجنت (بعضی‌ها ورودی JSON می‌گیرن: topic/text/message/reply)
- `GET /api/approvals` — صف تأیید
- `POST /api/approvals/<id>/approve` یا `/reject` — با body اختیاری `{"note": "..."}` برای درس دادن به ایجنت

## فایل‌های داده
- `prices.json` — قیمت‌های واقعی (CA$10 چت / CA$5 اپ / $79 پرمیوم)
- `dates.json` — ددلاین‌های واقعی کسب‌وکار
- `inbox_sample.json` / `reviews_sample.json` / `competitors.json` — نمونه برای ایجنت‌های چک‌کننده
- `memory/` — حافظه یادگیری هر ایجنت (JSONL)
